# Prithvi Raj & Harshini — Wedding Invitation

A royal, cinematic, luxury South Indian wedding invitation web experience for **Prithvi Raj & Harshini**.

## ✨ Features
- **Cinematic Opening Video**: Fullscreen intro with tap-to-open and sound toggle.
- **Scratch Card**: Interactive canvas reveal for wedding muhurtham.
- **Live Countdown Timer**: Real-time ticker to the auspicious celebration.
- **Lineage & Families**: Editorial family introduction with official wedding emblem.
- **Our Story**: Interactive flight journey from Chennai to Boston.
- **Schedule of Events**: Compact vertical timeline for all wedding ceremonies.
- **RSVP Card**: Instant WhatsApp confirmation & guest registration.
- **Ambient Nadaswaram Controller**: Floating audio playback.

## 🛠️ Built With
- **React 19**
- **Vite**
- **Framer Motion**
- **Lucide Icons**
- **Vanilla CSS**

## 🚀 Running Locally
```bash
npm install
npm run dev
```
